# deeplearning-digest

深度学习类论文解读 Skill，纯提示词，无其余依赖

## 功能

面向初学者的深度学习论文解读。输入一篇论文，输出一篇低门槛的讲解文章：

- 先给"地图"：问题背景、现有方法死穴、作者核心思路
- 陌生概念以「学术定义 + 直觉类比」双重解释
- 讲"为什么"而非仅仅"是什么"：关键设计连带动机与取舍讲透
- 实验以因果推理呈现，而非仅数据罗列
- 附带未来研究方向与可操作的后续实践路径
