# 学术格式速查（academic-format-cheatsheet.md）

> 本表与 `babeldoc_翻译守则.md` 的「§二 禁止改动的内容」「§五 原样返回（不译）」「§12b 图/表整体不翻译」完全对齐，是「形态冻结」原则的速查细节版。阶段 2 直译遇到拿不准的公式/符号/引用语法时，查本表确认"哪些必须原样、哪些才译"。

> 遇到不熟悉的公式/符号/引用语法，对照本表。核心原则：**原样保留，只译自然语言文字**。

## 一、LaTeX 公式（必须原样）
| 类型 | 写法 | 处理 |
|---|---|---|
| 行内数学 | `$E=mc^2$` | 原样，只译周围文字 |
| 独立公式 | `$$...$$` 或 `\begin{equation}...\end{equation}` | 整块原样 |
| 上下标 | `x_i`、`x^2` | 原样 |
| 希腊字母 | `\alpha`、`\beta`、`\theta` | 原样 |
| 分数/根号 | `\frac{a}{b}`、`\sqrt{x}` | 原样 |
| 求和/积分 | `\sum`、`\int_{a}^{b}` | 原样 |
| 矩阵 | `\begin{matrix}...\end{matrix}` | 整块原样 |

## 二、引用与编号（必须原样）
| 类型 | 写法 | 处理 |
|---|---|---|
| 文献引用 | `\cite{smith2020}`、`[1]` | 原样 |
| 章节 | `Section 3.2`、`第 3.2 节` | 编号原样 |
| 图表 | `Fig.1`、`图1`、`Table 2` | 编号原样 |
| 算法 | `Algorithm 1`、`Alg.1` | 原样 |
| 方程编号 | `(1)`、`Eq. 3` | 原样 |

## 三、单位与符号（必须原样）
| 类型 | 示例 | 处理 |
|---|---|---|
| 国际单位 | `kg`、`m/s²`、`J·mol⁻¹·K⁻¹` | 原样 |
| 百分比/区间 | `95%`、`95% CI [0.8, 1.2]` | 原样 |
| 统计量 | `p<0.05`、`F(2,34)=4.5` | 原样 |
| 化学式 | `H₂O`、`CO₂` | 原样 |

## 四、常见需"译"的部分（仅自然语言文字）
- 段落叙述、章节标题文字、图表标题文字、摘要、关键词。
- 例：`Abstract` → `摘要`；`Method` → `方法`；`Conclusions` → `结论`。

## 五、反模式（别这么干）
- ❌ 把 `$E=mc^2$` 翻译成「能量等于质量乘光速平方」并删掉公式。
- ❌ 把 `\cite{smith2020}` 改成「Smith 等人（2020）」后删掉引用标记（除非用户要求自然语言引用）。
- ❌ 把 `Fig.1` 改成「图一」（编号风格漂移）。
- ❌ 把单位 `kg·m/s²` "优化"成中文「千克·米每二次方秒」。
