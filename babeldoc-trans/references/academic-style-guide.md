# 学术翻译风格指南（academic-style-guide.md）

> 本文件为阶段 2 直译的学术文体参考：提供英→中 学术句式转换模板、时态/语态/缩写规范、常见术语参考译法、高频翻译陷阱（含数据保真与翻译腔诊断）与译后质量检查清单。与 `babeldoc_翻译守则.md` 的「四支柱」配套——本文件是「学术文体 + 回译」与「数据保真」两支柱的落地模板与速查。

**译者身份与立场**：你是一位专业学术译者。你深知，英译中的质量瓶颈从来不在对英文原文的理解，而在中文表达的上限——能精准解码英文只是起点，能用地道、凝练、符合学术规范的中文重新组织信息，才是译文成败的关键。因此你始终将「中文写作水准」置于首位：你的目标不是生产"英文句子的中文镜像"，而是撰写"以中文为母语的研究者愿意直接引用"的学术文本。

## 一、翻译质量准绳：信 · 达 · 雅

以严复「信达雅」为翻译质量准绳，三层优先级固定为：

```
信 > 达 > 雅
```

- **信（忠实）第一**：术语一致、数字无误、否定/肯定不反转、因果逻辑保留；宁可略生硬也不能歪曲原意。
- **达（通顺）第二**：在准确基础上调整语序、主被动转换、长句拆分、补衔接词。
- **雅（得体）第三**：学术用正式书面语，语域与原文匹配，避免口语化与翻译腔。

**总原则：中文优先，意合为主。** 既然译文成败取决于中文表达上限而非英文理解，翻译时便**不要**追求与英文逐词、逐从句对应，而应在理解整段逻辑后，用中文自然的语序重新组织信息——英文重形合（连接词、从句、被动），中文重意合（短句、流水、主动），应主动向意合倾斜。

**关键心法**：若读完整句英文后，脑子里先浮现的是英文结构、再想中文词，说明仍未摆脱句法束缚——应先想"这件事在中文里该怎么讲"，再考虑术语。

## 二、英→中 学术句式转换模板

| English Expression | 中文学术表达 |
|-------------------|------------|
| It has been well established that… | 已有大量研究证实… |
| The present study contributes to… | 本研究对…做出了贡献 |
| These findings have implications for… | 上述发现对…具有启示意义 |
| A growing body of literature suggests… | 越来越多的文献表明… |
| Controlling for confounding variables… | 在控制混杂变量后… |
| The results indicate that… / Findings suggest that… | 研究结果表明… / 研究结果显示… |
| Consistent with prior research… | 与前人研究一致 |
| It is noteworthy that… / Notably, … | 值得注意的是… |
| Several limitations should be acknowledged… | 存在一定局限性 |
| Future research could explore… / Further investigation is warranted… | 未来研究可以… |
| In summary, … / To conclude, … | 综上所述… |
| As shown in Table X / As illustrated in Table X | 如表 X 所示 |

> 用法：模板给出「地道学术中文」的惯用起手，用于消除逐词硬译产生的翻译腔；具体措辞仍需贴合上下文，不要套成固定八股。

## 三、学术文体规范（流畅度与可读性）

- **时态**：源文方法、结果段多为过去时（was / were / found）；普遍结论、背景用现在时（suggests / indicates），翻译时据此判断陈述的时态属性并落为对应的中文表达。
- **人称**：英文优先被动语态或 "this study"，翻译时对应处理为「本研究 / 本文」，避免直出 "I / we"。
- **缩写**：首次出现写全称并附缩写，如 "artificial intelligence (AI)"；之后直接用缩写。
- **引用格式**：保留原文引用样式（APA / MLA / Chicago），不转换；作者名、年份、页码原样。
- **动词驱动，去"进行"化**：中文学术写作偏好直接动词而非"对…进行…"的伪被动结构。不说"对模型进行训练"，而说"训练模型"；不说"对性能进行评估"，而说"评估性能"。"进行"仅当它确实带来节奏缓冲或强调时保留。搭配也要地道——中文不说的搭配不要因为英文用了某词就直接对应（如 "enable easier gradient flow" 不译"获得更顺畅的梯度流"，而说"让梯度流动更顺畅"或"改善梯度传播"）。另警惕把英文介词框架直接套入中文——中文动词往往自带方向性，优先用「动词+宾语」的直接结构，而非「对 / 将…施加 / 应用于…」的嵌套式表达。
- **信息密度动态调节（长句拆分）**：英文嵌套长句果断拆分为多个中文短句，或把后置定语转为前置小句 / 补充说明。但**不要**机械地"一句拆三句"——若中文能自然承载某个稍长复合句，保持它。判断标准：朗读时是否在换气点感到窒息。警惕过度精简——不要为"简洁"删掉英文中承载限定、对比或因果关系的成分；若直译会导致歧义，宁可多几个字也要把逻辑说清楚。
- **节奏与呼吸感**：连续出现超过 35 字无标点的分句时，插入逗号或拆句；可借用四字格、对偶、排比增强节奏，但**不**为修辞牺牲准确性；允许"具体来说""换言之""值得注意的是"等自然衔接语，但避免每段都以"此外"开头。
- **定语与状语重排**：英文"名词 + of / that 从句"的修饰结构，中文中更适合改为独立小句（「…，该…」需指代清晰且距离不远）、后置补充（「…，其…」需指代清晰）或括号注释；**禁止**超过 20 字的前置定语堆砌，也**禁止**连续多个"的"字结构（一句话里出现"的…的…的…"说明定语没消化好）。
- **话题与主语的即时性**：中文是话题驱动语言，读者期待在分句**前部尽早确认叙述主体**。若英文通过从句、分词结构或代词将主语后置，翻译时必须将其提前，或拆分为独立短句；不让"其""该""此"承担跨分句甚至跨句的指代功能——指代对象与代词之间隔了其他名词、或超过一个分句时，直接重复主语或用更明确的称谓，别让读者读到后半句才回溯找主体。技术概念首次在某段出现时，应先亮出主体再补述修饰，而非让它在解释性分句的末尾才登场。
- **逻辑显化**：英文隐含的因果 / 转折 / 递进，若仅靠中文语序已能体现，**不必**强行插入"因此""然而"；若中文语序不足以承载关键逻辑，则**必须**显化（可用"这样一来""反之""问题在于""结果是"等更自然的表达）。**特别警惕"从而 / 由此"的机械使用**——"从而"因果一目了然时直接逗号或句号断开，不必每句都"从而"；"由此"除非前文确实产生明确结果 / 推论否则不用。主语与指代的清晰性（避免主体后置、"其 / 该 / 此"跨句指代）见上方「话题与主语的即时性」与 §五「主语后置与跨句指代」。
- **短句节奏**：英文段落常连续多个短句（每段五六处句号），中文不应机械一一对应；语义衔接紧密的相邻短句改用逗号 / 分号串联，恢复中文段落的流动感。**修辞性独立短句**（强调停顿、讽刺收尾、情感爆发）必须保留独立成句，并入前句会杀死其修辞效果。
- **破折号（——）**：仅用于真正中断性插入、突然转折或戏剧性停顿；**禁止**用破折号夹住并列名词或同位短语（典型翻译腔），应改用顿号（、）或逗号。例：`代码坏味道——小毛病——一开始就出现` ✗ → `代码坏味道、小毛病一开始就出现` ✓
- **标点**：中文译文统一用全角标点（，。：；、？！）；英文冒号 `:` 出现在汉字之间时替换为全角 `：`，但 URL 中的 `://` 不替换。

## 四、常见学术术语参考译法

> 术语处理：首次出现的重要术语采用「中文译名（英文原词）」格式，后续直接使用中文；若某术语在中文圈尚无统一译法，**优先选择直观、无歧义的组合**，而非生造词。下列为高频通用译法示例；**优先以阶段 2 自建的 `<terminology>` 术语表为准**（见 `glossary-template.md`）。本表仅作起步参考，当与本文献领域既有用法冲突时，以术语表与上下文为准，不要强行套用。数字、公式、符号、单位**保持原样**不翻译，但其 surrounding text 要自然（如 "kernel size of 3×3" → "3×3 的卷积核大小"，而非"卷积核大小为 3 乘 3"）。

| 中文 | English | 使用场景 |
|------|---------|---------|
| 显著性 | statistical significance | 统计检验 |
| 自变量 / 因变量 | independent variable / dependent variable | 实验设计 |
| 假设检验 | hypothesis testing | 研究方法 |
| 文献综述 | literature review | 论文结构 |
| 研究局限性 | limitations | 讨论章节 |
| 实证研究 | empirical study | 研究类型 |
| 定性分析 / 定量分析 | qualitative analysis / quantitative analysis | 方法论 |
| 同行评审 | peer review | 发表流程 |
| 交叉验证 | cross-validation | 机器学习/统计 |
| 置信区间 | confidence interval | 统计推断 |
| 元分析 | meta-analysis | 综合研究 |
| 随机对照试验 | randomized controlled trial (RCT) | 医学/社科 |
| 相关性 vs 因果性 | correlation vs causation | 研究结论 |
| 可复现性 | reproducibility | 研究质量 |

## 五、高频翻译陷阱（数据保真 / 去 AI 味）

| 陷阱类型 | 示例 | 正确处理 |
|---------|------|---------|
| 假朋友（false friends） | "actually" ≠ 实际上（更接近「其实」「事实上」） | 按语境选准确含义 |
| 数字陷阱 | "十亿" = 1 billion（非 10 billion） | 中英数字单位对照确认 |
| 被动/主动混淆 | 中文多主动、英文多被动 | 按中文习惯调整语态 |
| 否定转移 | "I don't think he is right" ≠ 我不认为他是对的 | 译为「我认为他不对」 |
| 主语后置与跨句指代 | 英文靠从句 / 分词 / 代词把主语或指代对象后置，读者读到后半句才回溯找主体 | **高优先级**：翻译时把主语提前或拆独立短句；不让"其""该""此"承担跨分句 / 跨句指代——指代对象与代词间隔了其他名词或超过一个分句时，直接重复主语或用更明确的称谓 |
| 万/亿换算 | 万=10,000；亿=100,000,000，不能直译 million/billion | 1.5 万=15,000；3 亿=300 million；10 亿=1 billion |
| 多余连接词 | 因此/然而/此外/另外 过度堆砌 | 上下文已暗示关系时删去，不硬加 |
| 名词堆砌·过度名词化 | "进行了讨论"→"讨论了"；"这是一个非常重要的问题"→"这问题很重要" | 动词/形容词更自然时勿堆抽象名词；"的"字过多时精简 |
| 分裂句 | 英文 "It is … that" 硬搬成不自然的"是…的"结构 | 重组为自然中文，不保留 "It is … that" 骨架 |
| 被动语态不自然 / "被"字处理 | "被引入到生产代码库中"、"性能被提升了 5%" | 英文被动转中文主动 / 无主句 / 隐含被动：改"进入了生产代码库"、"性能提升 5%"；**不**为对应语法机械加"被"。但中文已固化的"被证明""被称为""被广泛应用"可保留，不必强行消灭 |
| 句号密集碎片化 | 英文短句连发逐句翻译后中文像弹幕 | 相邻短句语义衔接紧的改用逗号串联 |
| "通过…来…"套娃 | "通过引入模块来提升性能" | 动作主体模糊、欧化严重；直接说"用模块提升性能"，或拆分主从 |
| 情感强度漂移 | going on about 不译"鼓吹"；反讽 fine 不译中性"这篇" | 原文情感烈度不放大不缩小，选中文情感质地完全一致的对等词 |
| "取得了成功超越"类赘余 | 英文动词名词化再直译（"achieved a successful surpass"） | 直接动词化："成功超越了…" |
| "为获得…而…"生硬目的状语 | 英文 "to enable…" 直译 | 改"为使…" / "以便…" / "从而…"（但别滥用） |

> **情感强度对位**：原文情绪烈度不得主动放大或缩小。先判断该词是客观描述还是语境性反讽/情绪词，再选中文中质地一致的对等词；修辞性独立短句（反讽、收尾爆破）不可并入前句或翻成中性语气。

## 六、译后质量检查清单

每批译完、整体交付前，逐项自查：

| 维度 | 检查要点 | 严重度 |
|------|---------|--------|
| 完整性 | 有无漏译的句子/条目 | 高 |
| 准确性 | 数字、日期、专有名词是否准确 | 高 |
| 术语一致 | 同一术语全文译法是否统一（对照 `<terminology>`） | 高 |
| 逻辑 | 因果、转折、并列关系是否保留 | 高 |
| 语法 | 译文有无语法错误 | 中 |
| 流畅 | 有无翻译腔、读起来是否自然（连接词/名词化/句号密度/长定语） | 中 |
| 情感 | 情感烈度是否与原文本质地一致，无放大/缩小 | 中 |
| 格式 | 标点（含破折号）、编号、缩进是否与原文风格匹配 | 低 |

> 数据类条目（数字、单位、统计值）一律以「数据保真」为最高优先级：逐字保留，不修正、不补充、不四舍五入。

**终检五问**（输出最终译文前快速自问，任一不理想即重构该部分）：

1. 这段文字若发表在中文期刊，读者会觉得"这是中国人写的"还是"这是翻译腔"？
2. 朗读其中任意三段，是否会在某处卡壳或需要回读？
3. 有没有哪句可以删掉三分之一字数而不损失信息？
4. 连接词（从而、由此、因此、此外）是否比原文还多？（若是，说明过度形合化）
5. 有没有为追求简洁而漏掉原文的限定词（如"仅""分别""在…情况下"）？

## 七、处理弹性（自由度声明）

本文件提供方向与审美标准，而非操作清单——不应逐条机械检查，而应在翻译中内化这些原则。允许按具体学科、作者风格、句子复杂度弹性处理，目标是"好中文"而非"符合 X 条规则的中文"。若直译在某特定句中确实比意译更流畅、更不易产生歧义，**保留直译**。鼓励在保持学术严谨的前提下展现节奏多样性：有时简洁、有时舒展；有时正式、有时略带叙述性，避免全文只有一种单调节奏。**最重要的自由**：若某句英文用中文很难优雅表达，不要勉强贴着英文结构硬翻——先彻底忘掉那句英文的语法，用中文把同样的学术意思重新讲一遍。
